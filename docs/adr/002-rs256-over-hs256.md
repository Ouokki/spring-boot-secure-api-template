# ADR 002 — RS256 over HS256 for JWT signing

**Status:** Accepted  
**Date:** 2025-05-11

## Context

JWTs must be signed so resource servers can verify them without calling back to
the auth server on every request. Two common algorithms are available:

- **HS256** (HMAC-SHA256): symmetric — same secret used to sign and verify.
- **RS256** (RSA-SHA256): asymmetric — private key signs, public key verifies.

## Decision

Use **RS256** with a 2048-bit RSA key pair.

## Why not HS256?

HS256 requires every party that *verifies* tokens to know the signing secret.
In a microservices architecture that means sharing the secret across multiple
services — each additional holder is an additional attack surface. A
compromised service can forge tokens for any other service.

With RS256, only the auth service holds the private key. Resource services only
need the public key, which can be distributed freely (e.g. via a JWKS endpoint).
A compromised resource service cannot forge tokens.

| Concern | HS256 | RS256 |
|---|---|---|
| Secret distribution | Shared with all verifiers | Private key stays in one place |
| Token forgery if verifier compromised | Yes | No |
| JWKS endpoint support | No | Yes |
| Performance | ~10× faster | Slower but negligible at request scale |

## Key management

- Dev keys are generated by `scripts/generate-dev-keys.sh` and gitignored.
- Production keys are injected via `JWT_PRIVATE_KEY_PATH` / `JWT_PUBLIC_KEY_PATH`
  environment variables and should live in a secrets manager (Vault, AWS SM).
- Key rotation: generate a new key pair, update the env vars, restart the
  service. Tokens signed with the old key expire within `accessTokenTtlSeconds`
  (default 15 min) — no active revocation needed for access tokens.

## Consequences

- Startup fails if the PEM files are missing or malformed, which is intentional:
  a service that cannot verify tokens should not serve traffic.
- A `/auth/jwks` endpoint (returning the public key as JWKS JSON) is a natural
  future addition for resource service integration without out-of-band key sharing.
